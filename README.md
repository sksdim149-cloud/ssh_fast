# 🚀 Rust SSH Manager

Simple CLI tool written in Rust for managing SSH connections and mounting remote folders via sshfs.

## 📌 Features

- 🔗 Connect to remote server via SSH  
- 📁 Mount remote filesystem using sshfs  
- ⚙️ Automatic sshfs installation (pacman)  
- 🧠 Interactive CLI interface  
- 💻 Works on Arch Linux (and derivatives)

---

## 🛠️ Requirements

- Linux (tested on Arch Linux)
- `ssh`
- `pacman`
- `yay` (optional)
